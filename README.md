# 💱 Currency Converter

A modern and responsive **Currency Converter** built with **React**, **Vite**, and **Tailwind CSS**. This application allows users to convert currencies quickly and accurately with a clean, user-friendly interface.

---

## 📖 Overview

This project was built to strengthen my React skills while creating a real-world application. It demonstrates how to manage state, handle user input, fetch currency exchange rates, and build a responsive interface using modern frontend technologies.

---

## ✨ Features

- 💱 Convert between different currencies
- 🌍 Supports multiple international currencies
- 🔄 Swap currencies with a single click
- ⚡ Real-time exchange rate conversion
- 📱 Fully responsive design
- 🎨 Modern UI built with Tailwind CSS
- 🚀 Fast performance powered by Vite

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/MehmoodAhmed006/Currency-Converter.git
```

### Navigate to the project

```bash
cd Currency-Converter
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
